# Five previously nominated pathways in Swiss glandular endometrium

November 14, 2026. Prospective analysis of GSE266265 for issue #38. Known before this commit: the same five Finnish whole-tissue pathway candidates all pointed down in Rome; none passed the original validation rule. The two Swiss inputs, subtype labels, donor and technical overlap, row labels and pathway coverage have been examined without estimating Swiss disease-group expression differences. This additional study tests whether a common direction is visible within proliferative glandular epithelial cells. The population, corrected-count assay and rank universe differ across studies. ## Participants and measurement

Use the checksum-pinned epithelial trajectory object and Supplementary Data 1. Join only on the authors' exact sample key and check diagnosis and phase. Restrict to their DEG inclusion flag, proliferative phase and at least 20 retained cells of a given refined subtype per donor. A subtype needs at least two capture batches with both groups and at least three donors per group across those batches. Glandular alone passes. This leaves 21 subtype-eligible donors before capture restriction and six cases and seven controls in four mixed batches after it. Each capture batch belongs to one sequencing batch. Use all eligible glandular cells of these 13 donors. A donor supplies one score per endpoint. Do not substitute other cell types, phases, cutoffs, or single-group batches.

Use the integer-valued SCT depth-corrected count layer. In each donor, sum each feature across glandular cells, rank all 29,034 original features including zeros from low to high using average ties, and score a feature as 100 × (rank − 0.5) / 29,034. Take the arithmetic mean of mapped members for each locked pathway. The overall primary endpoint is the unweighted mean of the five pathway scores. Shared members contribute to each parent score by design; this endpoint measures a joint direction and does not count biologically independent pathways.

## Inference and interpretation

For each endpoint, compute the case-minus-control mean within each capture batch, then the unweighted mean of these four contrasts. Report percentile-point differences. Enumerate all 144 assignments of disease labels that preserve the case count within each capture batch. Count the observed assignment and two-sided absolute tails including ties within 1e-10 percentile points. The exact p-value is the extreme count divided by 144. This conditional reference assumes the donor labels are exchangeable within capture batches under the null. Disease status was observational. Compare the global test with 0.05. Only if it passes may individual pathways be called supported, each then requiring Holm-adjusted p ≤ 0.05 across the five. Always report all estimates, exact counts, marginal p-values and Holm values, regardless of the global result. A positive difference matches the earlier Finnish direction; a negative difference matches Rome. This decision cannot retroactively change either earlier study.

Two descriptive sensitivity checks are fixed. First, rank all features separately inside each cell using the same percentile rule, average those ranks over each donor's cells and compute the same pathway and overall contrasts. This changes how sparse measurements and variable cell yield affect scoring. Second, omit each shared batch in turn from the primary score contrast and report the min–max estimate; these bounds describe influence and are not confidence limits. For cross-assay context, recompute the earlier Finland and Rome effect directions on identical Swiss-covered pathway membership where possible. Their original reference features and donor contrasts stay fixed. These checks create no additional discovery claims. Report effect signs, dependency between the nested FGFR3 sets, cell and donor totals, attainable p-value resolution, source limitations, and independent numerical verification from the pinned inputs. No randomized sampling or seed is used.
