## Question and eligible population

Among women undergoing tubal sterilization whose laparoscopy excluded endometriosis, is the five-gene score higher in peritoneum than in the same person’s uterine endometrium? The estimand is the equally donor-weighted mean peritoneum-minus-uterus score difference, in within-array percentile points, in eligible women. One donor supplies one difference. The study comparison is between organs in women with no surgically detected disease. It does not require case peritoneum to have negative histology, nor can it establish the status of an unsampled lesion. [Recruitment and processing](https://doi.org/10.1038/s41597-020-00623-x)

1. Use only the pinned EndometDB Figshare v1 native tables. Use the source foreign keys in the audit. Require the *control* recruitment category and *healthy* confirmed status. Exclude unexpected endometriosis, missing or discordant diagnosis, and all case donors. Retain native P (peritoneum) and E (uterine endometrium) from the same donor. Hospital, intensity patterns and inferred GEO-to-native matches are never used to identify a donor.
2. Before decoding quantitative signals, compute common assay runs from the native metadata across both tissues. Require **exactly one common run** for the donor and exactly one distinct native specimen of each tissue within that run. Discard measurements in other runs. Freeze the resulting list of candidate donors, specimens and assays privately. The metadata audit finds eight such donors out of 14 anatomically paired donors. Five of the eight have exactly one assay per arm globally. Require the same platform, native processing and run for each retained pair.
3. Apply a blinded physical-address check against the pinned manufacturer WG-6 and HT-12 manifests following the repository’s chip census. Accept an assay only if its address set equals the 48,701 unique WG-6 v2 addresses, has no duplicate address and maps exclusively to WG-6. Native run number and common chip family alone do not verify physical identity. Exclude invalid or ambiguous assays before reading signals. A specimen needs at least one remaining assay, otherwise exclude its donor pair. For multiple valid assays of a specimen, average assay scores with equal weights. Repetition never increases the donor count. Disclose attrition and all reasons. Do not rescue cases using a combined matrix, another chip or cross-cohort normalization. [Source pins and chip identity method](GSE141549_CHIP_CENSUS_2026-11-14.md)
4. Do not require untreated status for the primary organ contrast. The two specimens share donor and recruitment context. The native release has no operation-date or visit key. A common laboratory run does not verify same-day collection, a shared cycle phase at collection, or a common hormonal exposure. The native survey’s default false conflicts with the medication distribution of the published control-peritoneum samples. The primary population includes treated or unknown exposure and cannot be called untreated. Prespecify one descriptive sensitivity using only matched uterine specimens with a single proliferative or secretory pathology classification and stored false medication status. Six of the eight metadata pairs currently meet these codes. Do not import GEO phase or exposure into native donors. Report phase counts, exposure limitations, unavailable peritoneal subsite and possible tissue-specific hormone effects. No post-outcome array pruning. Rank all 48,701 features within that assay in ascending order with average ranks for ties. ## Inference, interpretation and stopping

Use one primary comparison and one two-sided test at alpha 0.05. Enumerate all 2^n donor-level sign flips of the peritoneum-minus-uterus differences. The statistic is the absolute mean difference. Include ties with the observed statistic and use the exact tail count divided by 2^n. This model assumes independent donors and sign exchangeability at zero, conditional on the paired design. Tissue was not randomly assigned. Report the signed mean, number positive/zero/negative, two-sided p-value and the 95% compatibility set obtained by inverting the same test on differences minus each candidate common shift. Use attainable breakpoints, including endpoints, and state the common-shift assumption. The interval is for that model; heterogeneous responses limit its interpretation.

A single prespecified primary endpoint needs no multiplicity adjustment. Report the phase-restricted mean and leave-one-donor-out mean range descriptively, with no secondary significance calls, gene-wise inference, subgroup selection or pooling with prior studies. If fewer than six independent verified pairs remain, a two-sided exact test cannot attain 0.05 (best case 2/2^n). Close the inferential endpoint as **under-resolved at metadata/chip preflight**. Report capacity and attrition without opening target signals. Six or eight donors can still yield wide uncertainty. No equivalence margin is asserted and no effects are imputed.
