## Technical and clinical interpretation

After calculating the primary result we verified slide allocation in the original Agilent Feature Extraction headers. Each 16-character barcode contains a 12-digit slide barcode and grid position. The same slide barcode is in the original array name and scan filename for every record. The 36 array positions occupy 15 slides. The separate extraction protocol imbalance is concentrated among the infertile cases. These checks use source metadata and leave the primary estimate intact.

| Source header audit | Fertile control | Fertile case | Infertile control | Infertile case |

| Arrays with GE1_107_Sep09 protocol | 9 | 9 | 9 | 4 |
| Arrays with GE1-v5_95_Feb07 protocol | 0 | 0 | 0 | 5 |

Slides shared by multiple participants may induce correlated measurements that the patient-level interval does not capture. Slide fixed effects would absorb the entire four-group contrast. Within-array ranking removes common monotone scale changes but cannot remove feature-specific technical shifts. The frozen directional rule was met in this matrix. Biological attribution remains unresolved. The cohort comprises secretory-phase stage IV ovarian endometriosis, and its controls and recent hormone histories differ from the original UCSF eligibility criteria. No independent disease-wide or clinical claim follows. Retrieve the two compressed GEO files linked above to the ignored directory and retain them compressed. The analysis verifies the following SHA-256 values before reading expression.
