# GSE315857 canonical FOSB transcript position in proliferative endometrium

November 14, 2026 UTC. **Exploratory human-data computation.** The canonical FOSB transcript ranked 0.1982 percentile points higher at the case median than at the control median. Removing one woman at a time produced differences on both sides of zero. This is descriptive agreement with the prespecified direction in eight biopsies, sensitive to individual participants. ## What was measured

The authors obtained eutopic endometrial biopsies in the histologically dated proliferative phase and excluded IUD use and hormonal therapy in the three months preceding surgery. Eight distinct GEO libraries matched eight ENA BioSamples, experiments and runs in BioProject PRJNA1399448. Every matrix column matched a published clinical group by library name. One library-name prefix appears in both groups (two controls and one case); the others appear exclusively in two controls or three cases. Prefix meaning is unresolved. Eight participants and this source imbalance limit interpretation, and the plan specifies no p-value or population interval. Other pelvic pathologies, stage and fertility could not be addressed. The paper identifies the North Carolina IRB and Missouri sequencing core. Neither the recruitment venue for each sample nor donor-level non-overlap with other studies was verified. The authors report that the series derives from GSE272606. These accessions count once. [Primary study](https://doi.org/10.1093/reprod/xaag038) · [GEO](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE315857) · [ENA](https://www.ebi.ac.uk/ena/browser/view/PRJNA1399448)

The target, `ENST00000353609`, was the sole deposited transcript among the 13 annotated FOSB transcript identifiers. GENCODE v50 marks its version `.8` as protein coding, MANE Select and Ensembl canonical. The 22,961 unique named transcripts supplied the common background. Four unnamed rows were excluded. All 183,720 archived cells were finite and nonnegative, with 12,581 zero entries and 171,139 fractional positive entries. The deposited table is labeled raw counts, yet it lacks integer counts and its column totals vary. The publication and GEO report different processing methods. The frozen rank calculation only depends on within-biopsy ordering and includes ties. It can respond to changes in the target and in the background distribution. It does not estimate a FOSB gene-level fold change or resolve all splice forms. [GEO processed matrix](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE315nnn/GSE315857/suppl/GSE315857_Raw_counts_All_Samples.txt.gz) · [GENCODE v50 source track](https://hgdownload.soe.ucsc.edu/gbdb/hg38/gencode/gencodeV50.bb) · [Gene identity](https://www.ncbi.nlm.nih.gov/gene/2354)

This result adds a descriptive observation for a proliferative-phase canonical RNA transcript. The New Delhi secretory-phase analysis used an array probe and fertility-stratified means. Our two group medians and their sensitivity range cannot be pooled with that effect or interpreted as a predictive test. [Secretory-phase analysis plan](GSE120103_FOSB_PLAN_2026-11-14.md)

## Reproduction

The four analysis inputs occupied 1,184,232 bytes. The acquisition and audit stayed inside the 50 MB public-data budget. On CPython 3.12.14 the offline Python computation took 0.22 seconds and used about 25 MiB peak RSS. A separate base R 4.5.0 implementation read the matrix and sample metadata independently, used `rank(ties.method = "average")`, and reproduced the two group medians, difference and both delete-one bounds to at least 10 decimal places. No seed applies. [Python implementation](../../scripts/analyze_gse315857_fosb.py) · [Independent R check](../../scripts/r/verify_gse315857_fosb.R) · [Synthetic tests](../../tests/test_analyze_gse315857_fosb.py)

The following commands acquire only the necessary public inputs under the ignored directory. Keep them local. The script reads local files and emits only aggregate results.

```sh
mkdir -p data/private/gse315857
cd data/private/gse315857
curl -fsSL 'https://ftp.ncbi.nlm.nih.gov/geo/series/GSE315nnn/GSE315857/suppl/GSE315857_Raw_counts_All_Samples.txt.gz' -o counts.download
curl -fsSL 'https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE315857&targ=gsm&view=brief&form=text' -o childgpl.download
curl -fsSL 'https://www.ebi.ac.uk/ena/portal/api/filereport?accession=PRJNA1399448&result=read_run&fields=run_accession,experiment_accession,sample_accession,library_name,instrument_platform,instrument_model,library_layout,library_strategy,library_selection,center_name,first_public,study_accession&format=tsv' -o ena.download
curl -fsSL 'https://api.genome.ucsc.edu/getData/track?genome=hg38;track=knownGene;chrom=chr19;start=45450000;end=45550000' -o ucsc.download
cd ../../..
inputs=data/private/gse315857
python scripts/analyze_gse315857_fosb.py --matrix "$inputs/counts.download" --geo "$inputs/childgpl.download" --ena "$inputs/ena.download" --annotation "$inputs/ucsc.download"
Rscript scripts/r/verify_gse315857_fosb.R "$inputs/counts.download" "$inputs/childgpl.download"
python -m pytest -q tests/test_analyze_gse315857_fosb.py
```

The gzipped matrix SHA-256 is `fd83f667ab8df44b108ab499b2abbc0b16fd3b9b73fb2c899a410d908095df6d`. GEO and ENA response order or other metadata can change. The sorted group/library/GEO/SRA mapping has SHA-256 `a07ce9637047dc20843ddca0b487297f9208aa0e133b3d5666ac5ea98f2b9027`. The 13 sorted annotation records including transcript ID, gene, type and alphabetized tags have SHA-256 `4239eead87c0fc3d70885e19d04f3629e9712bec32a4d94b1f7b098e8757f72b`. The analysis ignores UCSC's per-request timestamp and requires the backing file `gencodeV50.bb`. It stops if a later default UCSC track uses a new annotation release. [UCSC locus response](https://api.genome.ucsc.edu/getData/track?genome=hg38;track=knownGene;chrom=chr19;start=45450000;end=45550000)

The permanent release provides a second exact annotation route if UCSC changes the default. With UCSC `bigBedToBed` installed, extract just this interval from the versioned remote file. Supply the resulting `.bed` path to `--annotation` in the same Python command. The 95 interval records produced the same 13-transcript annotation digest and aggregate result. The script also checks SHA-256 `f2709a357264408a1eeeda24b0dd8f56505b06520b51a09be678cbf5571e38d5` over the complete BED. The release layout and queried interval were verified independently using 75,573 bytes of genomic file and index ranges. [Versioned source](https://hgdownload.soe.ucsc.edu/gbdb/hg38/gencode/gencodeV50.bb)

bigBedToBed -chrom=chr19 -start=45450000 -end=45550000 \
