# Peking University First Hospital ovarian lesion RNA-seq panel check

We chose GSE282532 after the array discovery and follow-ups had been evaluated. The five fixed genes and signs in the discovery lock were already public to this team. This separate local specification was written after checking only study metadata, workbook structure and annotation format, before reading expression measurements for this analysis.

Validate the ten column aliases exactly against the second GEO description field and require them to pair by both the suffix in the worksheet and the numeric study sample title. Require consistent source tissue, one assay of each tissue per pair and five pairs. Check frozen original HGNC/Entrez symbol identities (including known aliases if required) against each measured Ensembl gene. Require a source gene ID to map uniquely to each panel gene. Report coverage and stop the five-gene test if a member cannot be resolved. The study also uses an independent hospital cohort and a sequencing assay. Only the approximately 10 MB provider workbook and GEO metadata are needed.

The worksheet records transcript-level FPKM. Exclude invalid Ensembl gene IDs; require distinct transcript IDs and finite, nonnegative abundance. Sum the FPKMs of all transcripts belonging to the same valid Ensembl gene, then calculate within-sample midrank percentiles across the complete deposited gene universe including zeros. Compare the frozen equal-weight, signed score in ovarian endometrioma versus the same person's uterine tissue. Use all 32 donor sign flips and the one-sided directional p-value for the single aggregate test. Report two-sided p, leave-one-pair-out range, each gene's magnitude, direction and five-gene directional Holm p. Also rank transcripts first, then average transcript percentiles for each gene; check the panel on this alternate scale. Sum-of-FPKMs is a within-study abundance summary. This test assesses tissue composition and expression in established lesions.
