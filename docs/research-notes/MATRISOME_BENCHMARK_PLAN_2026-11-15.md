# A scan-disjoint matrisome benchmark

November 15, 2026. The 34/37 identity result, the authors' 37 predictions, the genome-wide Finnish/Rome reversal, the Rome scan-order imbalance and the genome-wide Mumbai comparison were already known. This new array-level benchmark was specified before calculating its scores. It asks whether a simple uterine matrisome expression pattern derived solely in GSE51981 separates case and comparator arrays in GSE6364, Rome and Mumbai. The published fitted coefficients and the exact original transformation for an unseen cohort were unavailable in the inspected code tree. The study below examines the same biological feature family under a different, fixed estimator.

Use GSE51981 as the sole reference. Use the authors' 144 eligible phase records, retain only endometriosis and no-pelvic-pathology controls, and remove every GSE51981 array with a physical match to GSE6364 before fitting. Keep the other-pelvic-pathology group separate from healthy controls. Use the author's complete all-matrisome list, unambiguous GPL570 gene symbols and Entrez IDs, and the condition-blind intersection with the Rome and Mumbai platforms. One feature per Entrez gene. As a sensitivity fit the same estimator retaining the reused scans in the reference to show how much its inclusion changes this estimator.

Rank probes within each microarray, then average within gene. For each phase shared by cases and controls in the training data, compute the difference of the mean gene percentile between cases and controls. Give phases equal weight, then normalize this reference vector by its Euclidean norm. Compare reference scores for the 37 GSE6364 arrays by the within-phase proportion of case–comparator pairs in which the case score is higher (a tie contributes one half), reporting every phase and the pair-weighted total. Report the same pair statistic in proliferative Rome and mid-proliferative Mumbai, whose gene ranks use summed FPKM. No fitting, centering, tuning, or batch correction using target labels. No cut point, refit on the test set or search for a better scoring direction. This is a descriptive benchmark on already studied cohorts. Condition, treatment, source and processing imbalances limit interpretation, and the public GSE51981 records lack a donor key. An unmatched scan establishes technical separation only.
