# GSE141549 independent cohort eligibility audit

**November 13, 2026 (US Eastern). Decision: defer the external FOSB expression comparison.** Finland's EndometDB provides real donor, histology and hormone-medication records. In its native database, 38 donors have exactly one eligible analysis result. Only 25 of these donors are in run-by-phase groups containing both cases and controls. The smaller GEO workbooks and the native clinical tables use different identifiers. The two platforms use different FOSB probes and one platform has no controls. This audit inspected metadata, platform annotations, and workbook column headers and annotation strings. No expression value was evaluated.

## Recruitment and clinical meaning

The authors recruited cases at four hospitals in Finland and controls undergoing tubal ligation at Turku University Hospital. Surgery and histopathology established endometriosis in cases, and laparoscopy excluded endometriosis in controls. The original GSE51981 study used a UCSF tissue bank in the United States. Separate recruitment and institutions support an independent cohort comparison. Neither study supplies a cross-study subject key, and we attempted no participant matching. The Finnish control definition does not explicitly document the absence of every possible pelvic pathology. [Finnish study, Methods and Data Records](https://pmc.ncbi.nlm.nih.gov/articles/PMC7455745/) · [UCSF study](https://pmc.ncbi.nlm.nih.gov/articles/PMC4239429/)

The native survey explicitly records hormone medication as true or false. Its schema provides no exposure date or interval. Requiring an explicit false value excludes missing statuses but cannot verify the original study's three-month washout. Native histology distinguishes proliferative and secretory endometrium. The native eligible set has no early versus mid-secretory classification. A model using the Finnish definitions would be a separately specified directional comparison.

## Native database eligibility

The public Figshare version contains a PostgreSQL custom-format dump. The authors' application joins the assay result to a sample, then a patient. We followed those declared database relationships entirely within this release. We used the codebook's confirmed disease status together with recruitment category, exact endometrium tissue, explicit negative hormone survey and proliferative or secretory histology. All donors with multiple qualifying assays were excluded before examining outcomes, avoiding selection among repeated assays. ## Platform, identifiers and preprocessing

The public GEO brief SOFT file contains 408 records. All 408 unique titles appear exactly once in the 162 groups of the submitters' sample-link workbook. Its headers identify a GEO sample link and GEO sample codes. Neither establishes identity between this namespace and the native database patient or assay keys. The 47,897,831-byte HumanHT-12 workbook and 153,632,401-byte batch-corrected combined workbook also used GEO sample titles in their first-row sample columns. We inspected their XML column header and string dictionary without reading a result. [GSE141549 files and metadata](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE141549)

Among GEO records with an endometrium tissue characteristic and a primary CE or PE title (excluding titles marked replicate), GPL13376 has 62 patient and 38 control arrays. GPL10558 has 39 patient and zero control arrays. The actual manufacturer GPL13376 manifest lists exactly one row with FOSB or Entrez 2354 among 48,701 probes, `ILMN_1730706` (array address `0006040086`). The NCBI GPL10558 annotation maps FOSB to `ILMN_1751607`. Both HT-12 v4 manufacturer releases list the same 50-base probe sequence for comparison with the 50-base WG-6 probe. The HT-12 and WG-6 sequences differ and are not reverse complements. The combined workbook labels column A as Gene_symbol and B as Probe_Id. The complete shared-string dictionary contains FOSB and the HT-12 probe identifier, and does not contain the WG-6 identifier. The first two data cells in column B reference Illumina probe IDs. These checks did not establish an FOSB row pairing or identify which oligo generated each sample’s measurement. [HT-12 manufacturer release R1](https://ftp.ncbi.nlm.nih.gov/geo/platforms/GPL10nnn/GPL10558/suppl/GPL10558_HumanHT-12_V4_0_R1_15002873_B.txt.gz) · [HT-12 manufacturer release R2](https://ftp.ncbi.nlm.nih.gov/geo/platforms/GPL10nnn/GPL10558/suppl/GPL10558_HumanHT-12_V4_0_R2_15002873_B.txt.gz) The study performed log transformation and quantile normalization by chip generation and used ComBat for its combined analysis. The authors remapped probes to gene symbols during harmonization. A native symbol match by itself does not establish the probe, platform, log base, or one-to-one measurement. [GPL13376 manufacturer manifest](https://ftp.ncbi.nlm.nih.gov/geo/platforms/GPL13nnn/GPL13376/suppl/GPL13376_HumanWG-6_V2_0_R4_11223189_A.txt.gz) · [GPL10558 GEO annotation](https://ftp.ncbi.nlm.nih.gov/geo/platforms/GPL10nnn/GPL10558/annot/GPL10558.annot.gz) · [Published normalization and reannotation](https://pmc.ncbi.nlm.nih.gov/articles/PMC7455745/)

A separate Finnish test could use the native assay IDs after confirming how the two FOSB probe identities were represented in the combined matrix and whether the selected platform has estimable run/phase overlap. The authors' public interface documents gene visualizations. We could not verify an available official endpoint supplying the required per-assay numeric series; the home page returned HTTP 503 in this environment. The native archive offers a route without translating between the two identifier namespaces. The compressed PostgreSQL table for all normalized expression occupies about 2.44 GB inside its 2.96 GB ZIP. This audit did not download that table. [Database](https://endometdb.utu.fi/) · [Archive metadata](https://api.figshare.com/v2/articles/12195975/versions/1)

## Reproduce the native eligibility counts

The linked ZIP is a versioned Figshare file, size 2,955,844,826 bytes, publisher MD5 `e649e9231171e377e3a0e187e60b0abb`. The local audit obtained the exact two byte ranges below on November 14, 2026 UTC. The program checks their SHA-256 pins before using the release-specific ZIP restart positions. It restores only six metadata tables from the PostgreSQL contents index. The report contains aggregate counts. An optional `--manifest data/private/gse141549/native-eligible.csv` generates a restricted local manifest with study-local keys; keep this private. Code was verified with CPython 3.12.14, inflate64 1.0.4 and pytest 9.2.0. No random seed applies.

```bash
python -m pip install inflate64==1.0.4
mkdir -p data/private/gse141549
cd data/private/gse141549
URL=https://ndownloader.figshare.com/files/22809185
curl --fail --location --silent --show-error --range 0-65535 --max-filesize 65536 "$URL" -o archive-start.bin
curl --fail --location --silent --show-error --range 2955439946-2955839945 --max-filesize 400000 "$URL" -o archive-tail.bin
cd ../../..
python scripts/audit_endometdb.py --head data/private/gse141549/archive-start.bin --tail data/private/gse141549/archive-tail.bin
python -m pytest -q tests/test_audit_endometdb.py
```
