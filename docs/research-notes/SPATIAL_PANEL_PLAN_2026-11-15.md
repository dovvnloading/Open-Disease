Patient-matched lesions and eutopic tissue measure an anatomical contrast among affected women.

1. Recover the three full per-compartment summary tables (stroma, epithelium and macrophages). Look up the exact five manufacturer-verified symbols and report all results, including absence. Verify direction using an explicitly named directional gene in the primary text. Limma uses patient covariates on region measurements. This describes the authors' model.
2. Independently analyze the deposited region counts. Map the exact feature IDs given by the manufacturer's concurrent PKC to the DCC archive. Use all endogenous single-probe genes for the within-segment rank reference, retaining tied zeros; omit the single negative-control target. As a sensitivity, exclude segments with <10% endogenous probes exceeding the segment-specific limit of quantification. Define LOQ as max(2, geomean of floored negative probe counts times geometric SD squared), with SD estimated on logs and nonpositive counts floored at one for the threshold. Require intact paired anatomical compartments after filtering. Different from the original Q3/limma endpoint. Report filtered-segment totals versus the publication. Within each patient, tissue and compartment average region gene ranks before the matched lesion-minus-uterus contrast. Calculate the equal signed mean across all five genes; if a panel gene is not on the platform or has an ambiguous mapping, no five-gene endpoint. Enumerate all within-patient sign flips, using a one-sided test of the locked directions and Holm across all three compartments. Apply the same frozen procedure with all 60 profiled segments first, then report QC restriction. Report the number of complete patients, all-positive donor count and both estimates. At five pairs the minimum one-sided p is 1/32; the three-compartment procedure therefore cannot pass Holm 0.05. These tests quantify direction, magnitude and feasibility.
