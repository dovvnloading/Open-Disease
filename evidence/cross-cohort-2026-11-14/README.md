# Endometriosis cross-cohort screen

Start with the [study report](../../docs/research-notes/CROSS_COHORT_DISCOVERY_RESULTS_2026-11-14.md) for design, limitations and reproduction commands. All measurements here aggregate across donors.

| File | Quantity and interpretation |
| --- | --- |
| [discovery_gene.tsv](discovery_gene.tsv) | One row per shared Entrez gene, excluding FOSB. `effect_pp` is the equally weighted average of seven Finnish within-run and within-phase case-minus-control differences in rank percentile points. |
| [discovery_pathway.tsv](discovery_pathway.tsv) | The same analysis for each eligible human Reactome pathway. `members` counts measured shared genes after projection. Both discovery tables give the signed standardized statistic, two-sided exact tails, and synchronized family maximum-statistic tails out of 12,096 assignments. |
| [nominations.json](nominations.json) | Public discovery lock, including exact pathway memberships, directions, input-universe digests and [the nomination commit](https://github.com/dovvnloading/Open-Disease/commit/f2a3755ff055cde241e0eaaaedc11a1471270beb). |
| [validation.tsv](validation.tsv) | All ten locked Rome comparisons. Exact directional p-values use 3,003 assignments. Holm adjustment covers all ten. Deletion bounds omit one woman at a time. |
| [validation.svg](validation.svg) | Aggregate cohort comparison figure, generated by [the plotting script](../../scripts/plot_cross_cohort_validation.py). |
| [phase_sensitivity.tsv](phase_sensitivity.tsv) | All ten nominations split by Finnish phase. This diagnostic was specified after the external result and carries no new inferential test. |
| [melbourne_genes.tsv](melbourne_genes.tsv) and [melbourne_probes.tsv](melbourne_probes.tsv) | Separate five-gene follow-up using Melbourne's cycle-adjusted published probe statistics. A missing gene is outside its high-detection test family. [Follow-up report](../../docs/research-notes/MELBOURNE_FIVE_GENE_RESULTS_2026-11-14.md) |
